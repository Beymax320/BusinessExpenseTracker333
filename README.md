# BusinessExpenseTracker — лабораторна робота №2, варіант 2

.NET MAUI / MVVM. Трекер бізнес-витрат для ФОП.

## Реалізовано в лабораторній №2
- другий екран «Деталі / редагування витрати»;
- Shell-навігація між екранами;
- передавання `id` витрати через query-параметр та `IQueryAttributable`;
- контракт `ILifecycleAware` для ViewModel;
- делегування `OnAppearing` / `OnDisappearing` із code-behind у ViewModel;
- діагностичні повідомлення життєвого циклу App у Output;
- збереження незавершеного введення через `Preferences` і його відновлення.

## Перевірка
1. Додати витрату.
2. Натиснути на неї — відкриється другий екран.
3. Повернутися назад.
4. Ввести чернетку в поля, згорнути застосунок і розгорнути — введені значення мають зберегтися.
